# Страницы и ссылки Enduro Vietnam

Содержимое переносится без зависимости от Creatium. Визуальное совпадение отложено по запросу владельца: сейчас приоритет — страницы, адреса и последующее редактирование.

- `page-index.json`: все 53 найденные доступные страницы, URL и файл каждой страницы.
- `exported-pages/*.json`: редактируемые страницы, из которых работает общий шаблон сайта. `blocks` хранит текст и форматирование, `links` — ссылки, `images` — локальные изображения. Изменения в JSON требуют пересборки сайта для публикации.
- `link-ledger.csv` и `link-ledger.json`: все 5 602 вхождения исходных ссылок. Поле `originalHref` сохраняет старую запись, `href` — нормализованный рабочий адрес. Внутренние ссылки ведут на текущий сайт.
- `pages.json`: исходный текстовый инвентарь, включая повторяющиеся мобильные и десктопные варианты. Это архив, а не источник нового шаблона.
- `routes.json`: доступные URL, старые ошибочные URL, проверенные замены и недоступные исходные страницы.
- `assets.json`: соответствие исходных изображений и шрифтов локальным файлам в `public/assets`.

Оригинальная главная пока использует `homepage.json` и собственный шаблон. Полный экспорт её текста, ссылок и изображений также находится в `exported-pages/home.json`. Все страницы доступны через `/site-map`.

10 ошибочных старых путей перенаправляются на точные существующие страницы. 7 URL уже возвращали 404 на исходном сайте и не имеют подтверждённого содержимого. Из них только `/aboutourclinic` встречается в публичных ссылках: его 27 вхождений сохранены в реестре, но не публикуются как работающие ссылки. Остальные шесть — пустые шаблонные адреса из исходного sitemap.

Внешние ссылки сохранены. Соцсети, мессенджеры и YouTube обслуживаются сторонними сервисами. Получателя заявок и закрытые настройки Creatium нельзя извлечь из публичных страниц; реальная отправка формы ещё не настроена.

Проверка маршрутов: `python3 scripts/check-routes.py`. Отчёт: `.shipstudio/route-check-report.json`.
