# Публичная демонстрация на GitHub

Результат: отдельный `mansur4-jan/enduro-vietnam-showcase`, полный код в `application/`, демонстрационный сайт в `site/`. GitHub Pages публикуется отдельным Actions workflow. Исходный рабочий проект и локальная БД сохраняются.

Публичный снимок включает только открытые маршруты и фотографии. Приватная БД, заявки/контакты клиентов, outbox, роли, MFA, env, credentials, runtime caches не передаются. Формы снимка заменены прямыми ссылками Telegram/WhatsApp; сохранение заявок/CMS остаётся в полном серверном приложении. Демонстрация noindex, отдельный URL, основной домен не переключается.

Экспорт: `node scripts/export-github-showcase.mjs` при работающем localhost:3000. Публикация: отдельный commit/push подготовленного дерева `.shipstudio/github-publication`. В репозитории `application/public` содержит общие фото; workflow копирует их в Pages artifact. Подпапка сайта учитывается в адресах HTML/CSS/runtime. Каталоги демонстрации фильтруются на клиенте по публичным данным снимка, сохраняют параметры URL и пагинацию. Источник живой фильтрации приложения остаётся `CatalogListing`.

Применены: общий маршрут базы «собственный сервер» только для разделения static preview/production и код/данные/секреты; engineering-memory, validation; shipstudio-team для сообщения коммита. Next/TypeScript используются уже установленные; Pages workflow сверён с официальной документацией GitHub.

Приёмка: экспорт всех публичных URL, локальные ресурсы/якоря, браузер RU-главная/город/тур/аренда desktop/mobile, параметры каталога, публичный HTTP и Actions после push. Доставка заявок на Pages не заявляется.

Первый deployment принят (Actions success и HTTP /ru/). Обновлённый снимок содержит 178 страниц и 13 redirects; полный код и тема обновляются в application/. Публичные проверки без приватных данных публикуются в verification/.
