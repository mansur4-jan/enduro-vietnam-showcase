# Инвентарь S01

Источники: локальный скачанный проект, его `.shipstudio/source`, DOCX ТЗ v1 и лист «Обход URL» доступного прежнего XLSX-аудита. Документ извлечён в `TZ_v1-extracted.txt`; исходный DOCX не изменялся.

## Страницы и адреса

53 доступные страницы: 28 EN и 25 RU. 17 адресов исходного сайта имеют 404; для десяти ранее найдена точная существующая замена, семь остаются 404 без выдуманного содержимого. Карта `data/url-map.csv` содержит 70 строк: исходный путь, архивный HTML, редактируемый JSON, тип, язык, title, состояние, действие и происхождение.

`03_existing_urls.csv` и остальные CSV-приложения ТЗ не предоставлены и не найдены среди доступных материалов. Поэтому сверка именно с этим CSV не выполнена. Доступный XLSX-аудит содержит лист «Обход URL»; его адреса включены в сравнение и не добавили новых путей. Аудит используется как историческое свидетельство, не подтверждение текущих цен.

## Зависимости

| Область | Факт / ограничение |
| --- | --- |
| Creatium | Исходные HTML/CSS/JS и настройки находятся в закрытом локальном архиве; runtime нового приложения их не подключает. Редактор и закрытая база не экспортированы. |
| Медиа | Изображения и используемые шрифты в `public/assets`. Последняя локальная HTTP-проверка сверяет 1 911 вхождений изображений с существующими файлами. Права использования не подтверждаются фактом скачивания. |
| Недоступные фрагменты | 106 объявленных Creatium-фрагментов возвращали 404 при предыдущем скачивании; URL/ответы записаны в `source/dynamic-resources.json`. Новое сетевое скачивание в S01 не выполнялось. |
| Видео | YouTube остаётся сторонним сервисом; в локальном режиме iframe не загружается. Видеофайлы и права на них не перенесены. |
| Контакты | Исходные публичные контакты сохранены в данных; действия Telegram/WhatsApp, tel/mailto отключены в dev. Получателей уведомлений и секретов в отчёт не копируем. |
| Формы | Только собственный `/api/booking`, без исходного endpoint, БД и транспортов. Local mode даёт 503; ни почта, ни бот не вызываются. |
| Аналитика | Рабочие Google/Yandex-счётчики обнаружены в архивном HTML. Они не перенесены в app/components/lib и не исполняются. Идентификаторы не переписываются в этот отчёт. |
| Google Sheets | Ссылки/ID не найдены в страницах, данных и runtime-конфигурации. Не читались и не изменялись. Нужен подтверждённый источник для дальнейшего импорта. |
| Git | `.git` отсутствует. Ветка и коммит недоступны; Git не инициализирован вместо существующей истории. |

## Сохранение исходного состояния

До изменений S01 сохранены 529 файлов кода, контента, медиа и конфигурации в `.shipstudio/backups/s01-original`; manifest содержит размеры и SHA-256. Активный корень проекта — рабочая копия после сохранения этой исходной версии. Первоначальные архивы скачивания и экспорта не перезаписываются. Резервная копия не находится в `public`; прямой HTTP-запрос к её manifest возвращает 404.

Применены разделы общей базы: восстановление сайта, инженерная память, формы, URL/SEO, проверка результата и каталог источников инструментов. CMS, серверное развёртывание, импорт в Sheets/БД и переключение домена в S01 не выполнялись.
