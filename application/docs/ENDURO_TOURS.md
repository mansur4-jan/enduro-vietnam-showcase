# Русский шаблон эндуро-туров

Источник дизайна: `content/enduro-tours/reference-dalat-3h.html`, неизменённая копия переданного clean-blocks v4. Общий renderer: `components/tours/EnduroTourDetail.tsx`; runtime, CSS и данные разделены. Приёмка: `scripts/check-enduro-tours.mjs`, текущий отчёт `.shipstudio/enduro-tour-checks.json`.

## Границы и владельцы

Новый дизайн применяется к десяти опубликованным RU-эндуро-турам Далата, Нячанга, Дананга и двум трёхдневным маршрутам из Далата. EN, дорожные мототуры, аренда, главная и городские страницы используют свои прежние шаблоны. Маршруты и canonical не меняются. Закрытый предпросмотр продолжает использовать OfferingDetail без публичной формы.

Название, описание, цена, длительность, уровень, размер группы, фотографии, варианты и условия читаются из `published_data`, как и прежде. Новых параллельных CMS-записей нет. Парсер `lib/enduro-tours.ts` берёт обзор, шаги программы и включения из описания конкретного продукта, исключает соседние карточки старого конструктора из списка моделей. Общую цену и длительность берём только из структурированных полей, не из повторяющихся текстовых карточек исходника. Спорные модельные тарифы не публикуются как подтверждённые варианты.

Структура: hero → быстрые якоря → ход тура → маршрут → экипировка → мотоциклы → сопровождение → условия → галерея → цена → FAQ → другие туры → заявка. Старые anchors сохранены дополнительно. Фото открываются в отдельной вкладке без обязательного JavaScript; FAQ — native details. Меню поддерживает Escape, focus trap/return, inert и очистку обработчиков.

Форма использует действующий LeadForm и `/api/leads`: offering_id, source_path, дата, участники, комментарий, согласие и опубликованный ценовой снимок. Реальная доставка email/Telegram остаётся внешним незавершённым этапом; сохранение в БД не выдаётся за доставку.

## Визуальный контракт

Точные source tokens: orange #f15a24, pine #173d2a, pine-dark #0d281b, ink #171717, text #262a26, muted #59605a, cream #f6f5f0, pale #e8efe9, line #dfe3dd; max 1240px; header 74/64px; радиусы 10/16/20px. Manrope 400–800 и Bricolage Grotesque 500/600/700 размещены локально. Bricolage не содержит кириллицу; для русских букв явно задан Manrope, чтобы не возникал случайный serif fallback. Breakpoints исходника: 600, 900, 1250px. Секции 58/48/42px.

Преднамеренные исправления: прозрачный логотип при скролле; боковая навигация скрыта до 1600px, чтобы не перекрывать контейнер; ширина screenish контейнера соответствует мобильным gutters; настоящая форма вместо demo alert; рабочие мессенджеры вместо декоративных подписей; исходные фото вместо Unsplash; нет имитации отсутствующего видео или обещания двух конкретных гидов. Размеры защиты и выдачу подтверждаем, не обещаем универсальный комплект.

## Проверки

Приёмка завершена: 10 туров × 8 ширин = 80 браузерных проходов; 300/300 проверок без ошибок. Проверены все фото, уникальные IDs/якоря, опубликованные цены, FAQ, меню/Escape/Tab-trap и реальная удаляемая тестовая заявка с correct offering_id/source_path и двумя заданиями очереди. Computed styles сравнивались с локальным HTML на восьми ширинах; допустимые отличия — текстовые размеры заголовков, исправленные мобильные gutters и явный кириллический fallback. Это не pixel-score. Регрессия Далата 9/9 при 1440px. Production build и lint --quiet прошли. Общая проверка: 186 маршрутов, 306 ссылок, 330 изображений, 2212 integrity checks и 166 SEO-страниц; 0 ошибок. Проверено отображение нового шаблона на localhost:3000. Общие правила: реконструкция, Client-First, компоненты, медиа, SEO, формы и validation из `/Users/KuznecovAndrei/mega-project-builder/`. Инструменты фактически проекта: Next 16.3.8 / React 19.2.3, PostCSS, Sharp, собственный CDP harness.

Подготовлены 32 уникальные фотографии всех десяти туров в AVIF/WebP, с реальными размерами, SHA-256 и source URL (`content/enduro-tours/media.json`). Полный набор фотографий каждого предложения доступен через раскрытие галереи. Новые CMS-фото вне manifest используют действующий файловый pipeline каталога.
