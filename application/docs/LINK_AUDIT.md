# Проверка ссылок и дублей

Проверен локальный production runtime после импорта XLSX. Применены правила SEO, проверки результата и инженерной памяти общей базы. Проверка не меняет исходные архивы или записи XLSX.

Исправления:
- Три старых EN-адреса туров открывали вторую копию карточки: теперь постоянный 308 на основной адрес с сохранением query. Уже существующие RU-редиректы также проверены.
- Четыре ошибочно вложенных legacy rental URL теперь ведут непосредственно в русскую аренду с нужным городом. Приоритет закреплён в Next config, карта находится в content/canonical-redirects.json.
- Заголовки каталогов теперь отражают город, категорию и партнёра.
- Шаблонные Facebook/Twitter/VK ссылки groupname отключены при выводе; исходные данные и архив сохранены.

Результат: 186 маршрутов, 276 различных внутренних ссылок, 174 уникальных sitemap URL; расширенный обход 228 адресов с query/пагинацией, 146 переходов по якорям, 258 ресурсов, 1013 проверок без ошибок. SEO: 166 страниц без ошибок. Build и lint прошли. В браузере проверены старый адрес тура и вложенный адрес русской аренды; console errors отсутствуют. Две активные внешние ссылки (Instagram, Creatium) ответили HTTP 200.

У 69 предложений уникальные source IDs, inventory codes и публичные адреса; совпадающих полных rental payloads нет. Одинаковые названия моделей соответствуют разным позициям XLSX, поэтому не удалены. RU/EN одной позиции и фильтры с одинаковым title не считаются случайными дублями.

Семь исходных адресов без содержимого по-прежнему намеренно отвечают 404: достоверной замены в источнике нет. Известные конфликты цен, групп и тарифов XLSX описаны в WORKBOOK_REVIEW.md и этой проверкой не закрываются. Удалённый production domain/edge не проверялся: проверен текущий локальный проект.

Отчёты: .shipstudio/link-integrity-checks.json, public-route-checks.json, seo-checks.json, external-link-checks.json. Повтор: node scripts/check-link-integrity.mjs (production runtime на 3001); APP_URL=http://localhost:3001 node scripts/check-public-routes.mjs, затем check-seo.mjs.

Повторная проверка после исправлений RU-главной: 186 маршрутов, 278 внутренних ссылок, 174 sitemap URL; расширенный обход 234 адресов, 224 якоря, 286 ресурсов, 1131 проверка без ошибок. SEO — 166 страниц без ошибок. Отчёты в .shipstudio обновлены.

После городских страниц: 186 маршрутов, 284 внутренних ссылки, 294 изображения, 174 sitemap URL; расширенный обход 242 адресов, 710 якорей, 315 ресурсов, 1662 проверки без ошибок. Аудитор различает настоящий атрибут id и data-…-id; канонические ID записей не переименовывались ради проверки. SEO: 166 страниц без ошибок.
