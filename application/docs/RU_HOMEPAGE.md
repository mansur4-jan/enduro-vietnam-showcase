# Русская главная из HTML

Источник: content/homepage-ru/reference.html (неизменённая копия предоставленного файла). Изменён только вывод /ru; остальные страницы и записи каталога не редактировались. Рабочие артефакты body.html/styles.css воспроизводит node scripts/prepare-ru-home.mjs. Стили имеют префикс .ru-aggregator; общая система каталога сохранена.

Сохранены все 11 секций main, порядок блоков, тексты будущих направлений, сетки, палитра, типографика и media queries 520/820/1024/1100/1280 px. 28 исходных URL фотографий локализованы и декодированы; 9 файлов Manrope/Unbounded также размещены локально. MP4 assets/enduro-vietnam-hero.mp4 отсутствует в переданном комплекте: вместо запроса 404 используется его исходный постер. Фильтр логотипа исправлен, потому что brightness/invert в источнике давал белый прямоугольник.

Существующие города/туры/модели связаны с реальными RU-маршрутами. Будущие города/форматы и Facebook без указанного адреса открывают форму подбора. Подтверждённые Telegram, WhatsApp, Instagram, TikTok, YouTube, Google Maps и Tripadvisor подключены через content/homepage-ru/contacts.json. Telegram для связи и канал различаются. Карта обозначена как Далат; адрес Tripadvisor сохранён из исходного экспорта. Автоматический GET Tripadvisor вернул 403, остальные проверенные соцссылки — 200. Не созданы вымышленные услуги или новые страницы. Поиск различает туры и аренду, неизвестные направления отправляет в подбор. Меню/модальное окно поддерживают Escape, фокус и возврат прокрутки; движение ленты приостанавливается при взаимодействии и reduced motion.

Обе формы сохраняют общую заявку через /api/home-inquiries, без подмены её существующим туром. Миграция 005 разрешает NULL offering_id для таких заявок, сохраняя FK, organization_id и RLS. Запись, событие и две очереди уведомлений фиксируются одной транзакцией; повтор защищён idempotency key. Реальная внешняя доставка по-прежнему не настроена. Демо-успех удалён. Тестовая заявка и её очередь удалены после проверки.

Исправления по замечаниям владельца хранятся в content/homepage-ru/refinements.css и применяются генератором после исходных стилей. Фон обёртки логотипа при прокрутке прозрачный. Dropdown открывается при фокусе, вводе и повторном клике; первый экран не обрезает его, а слои полей находятся над следующей секцией. Кнопки городов имеют высоту 42px. На desktop аренда компактнее: сетка 430px, на экранах высотой до 750px — 380px; проверяется отсутствие обрезания содержимого. Междугородний блок явно обозначен как мототуры. «Эндуро» ведёт на /ru/all-tours?q=эндуро — опубликованные туры, соответствующие поиску, включая многодневные.

«Быстрый ориентир» формируется сервером из опубликованного каталога через lib/homepage-price-overview.ts: 11 реальных вариантов Далата, Нячанга, Дананга, междугородних мототуров и аренды, с актуальными ценами, длительностью и прямыми ссылками. Ещё три будущих формата обозначены «по запросу» и открывают подбор. Цены и наличие для них не выдуманы. Обновление утверждённых данных каталога меняет таблицу без ручной правки HTML. Runtime получает версию HTML/CSS/JS, чтобы после обновления страницы обработчики не оставались привязаны к старым элементам.
