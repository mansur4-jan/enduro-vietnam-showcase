# Экспорт Enduro Vietnam

Текущий приоритет владельца — все страницы, ссылки и редактируемое содержание. Визуальная сверка остановлена по его запросу; совпадение дизайна не является критерием готовности этого экспорта.

## Что сохранено

53 обнаруженные доступные публичные страницы, русский и английский варианты, исходные метаданные, тексты, форматирование, 5 602 вхождения ссылок и локальные изображения/шрифты. Исходные HTML, CSS, JS и результаты скачивания находятся в `.shipstudio/source` как архивные материалы. Они не используются как код нового шаблона.

`content/page-index.json` связывает URL с отдельными редактируемыми файлами в `content/exported-pages`. Общий шаблон страницы читает эти файлы; изменённые файлы попадают на сайт после пересборки. Главная пока использует ранее созданный собственный шаблон и `content/homepage.json`; полный исходный текст и ссылки главной дополнительно сохранены в `content/exported-pages/home.json`.

Полный список страниц доступен на `/site-map`. CSV для работы со ссылками: `content/link-ledger.csv`. Подробности структуры данных: `content/README.md`.

## Проверенные исправления ссылок

10 старых ошибочных путей перенаправляются HTTP 308 на точные существующие страницы. Внутренние ссылки нормализованы на текущий хост. Отсутствующий в оригинале якорь `/ru#uslugi` восстановлен на заголовке раздела услуг и стоимости аренды. Исходные значения сохранены в поле `originalHref` реестра.

7 адресов из оригинала не имеют доступной страницы или подтверждённой замены. Только `/aboutourclinic` встречается в ссылках страниц (27 вхождений). Он сохранён в реестре, но не публикуется как рабочая ссылка. Остальные шесть — пустые шаблоны из исходного sitemap. 106 объявленных фрагментов Creatium также возвращали 404: записаны URL и результаты запросов. Недоступное содержимое не выдумано.

## Архивы и запуск

`.shipstudio/enduro-vietnam-source.zip` — исходный архив материалов скачивания.

`.shipstudio/enduro-vietnam-export.zip` — полный проект: страницы, ссылки, локальные ресурсы, исходный архив, код нового сайта и проверки. Не содержит `node_modules`, кэшей сборки, истории Git или секретов. Внутри есть `export-checksums.json`; все файлы проверены по SHA-256 и CRC ZIP.

После распаковки: `npm ci`, затем `npm run dev -- --port 3000`. Для production: `npm run build`, затем `npm run start -- --port 3000`. Не переносите папки `.next*` из другого запуска: они создаются автоматически.

Проверка: `python3 scripts/check-routes.py`. Для другого локального URL задайте `MIGRATION_BASE_URL`. Отчёт `.shipstudio/route-check-report.json` содержит результат по каждому адресу и внутренним переходам.

Внешние сервисы остаются внешними: соцсети, мессенджеры и YouTube. Получателя заявок и закрытые настройки Creatium публичный экспорт не содержит; реальная отправка формы пока не подключена.
